### Sources Help

Paste a GitHub link above and press ↩ to pick a marketplace's plugins, or edit the list on the left, one source per line (`#` starts a comment). ⌘T tests the list here, ↩ saves and updates, ⎋ cancels. An empty list goes back to the workflow configuration, then the defaults.

- `https://github.com/<owner>/<repo>`: a repo of skills, or every plugin of a Claude marketplace
- `<owner>/<repo> <plugin>`: one plugin of a Claude marketplace
- `https://github.com/<owner>/<repo>/tree/<branch>/<folder>`: the Markdown (`.md`, `.mdc`) files in a folder; add `:<pattern>` to pick some, e.g. `…/data/patterns:*/system.md`

A prompt's name and description come from its frontmatter, else its file name and first line of text.
