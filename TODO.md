### Find and Replace

- [Supercharging Vim search](https://www.mattlayman.com/blog/2019/supercharging-vim-blazing-fast-search/):
  article about quickfix reflector
- [quickfix-reflector.vim](https://github.com/stefandtw/quickfix-reflector.vim):
  to be used with other alternatives as it allows to make the quick fix list
  writable!
- [vim-grepper](https://github.com/mhinz/vim-grepper): together with the above
  might be a nice solution
- [ctrlsf.vim](https://github.com/dyng/ctrlsf.vim#quick-start): an all in one
  plugin for searching and replacing
- [far.vim](https://github.com/brooth/far.vim): same as above
- [nickjj dotfiles .vimrc](https://github.com/nickjj/dotfiles/blob/master/.vimrc):
  this guy uses vim-grepper and some other crazy key bindings (maybe could be
  made easier if he used quickfix-reflector)
